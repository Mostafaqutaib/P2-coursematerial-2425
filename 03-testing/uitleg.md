
# 🎯 الفكرة الأساسية: ليه نسوي Testing؟

التستّات (Unit Tests) هي ملفات جاهزة مكتوبة عادةً بـ **pytest**، هدفها:

1. تتأكّد إنّ **الكود اللي تكتبه يعمل زي ما هو مطلوب**.
2. تساعدك تعرف وين الأخطاء بسرعة.
3. تمنع إنك "تكتب حل غلط ويشتغل بالغلط".

يعني بدل ما نجرّب يدويًا، نخلي pytest يتحقّق من النتائج بشكل دقيق.

---

# 🧪 كيف تشتغل التستات في الكورس؟

في كورس Programmeren 2 (رابطك اللي عطيتني)، كل تمرين غالبًا فيه:

* ملف:
  `assignment_name.py` → هنا تكتب الحل.

* وملف:
  `test_assignment_name.py` → هذا فيه التستات الجاهزة.

الاختبارات تكون بشكل:

```python
from assignment import my_function

def test_my_function():
    assert my_function(2, 3) == 5
```

الفكرة: **pytest ينادي دوالّك ويتأكد إن النتيجة صح**.

---

# 🧨 كيف تشغّل التستات؟

في terminal داخل المجلد:

```
pytest
```

أو:

```
pytest test_file.py
```

لو طلع أخضر → مبروك ✨
لو طلع أحمر → يعطيك error ويقول لك "كنت متوقع 5 لكن حصلت 7".

# 📘 طيب… كيف أفهم التمارين عن طريق التستات؟

هذي أهم نقطة!
أصلاً أغلب التمارين في الكورس **تفهمها من التستات نفسها**. خلّيني أشرح خطوة بخطوة:

---

## 👣 1. شوف اسم الدالة المطلوبة

مثال من تمرين lambda:

```python
from lambdas import add_one

def test_add_one():
    assert add_one(4) == 5
```

معناها:
أنت لازم تكتب دالة اسمها `add_one` وتسوي +1.

---

## 👣 2. شوف أنواع المدخلات والمخرجات

مثال:

```python
assert filter_even_numbers([1,2,3,4]) == [2,4]
```

معناه:

* المدخل: list أرقام
* المخرج: فقط الأرقام الزوجية

---

## 👣 3. شوف الحالات الغريبة (edge cases)

التستات تكشف لك أشياء ما هي مذكورة بالنص.

مثال:

```python
assert reverse_string("") == ""
```

معناه:
لازم تدعم السلسلة الفارغة.

---

## 👣 4. اربط الحل بطريقة الكورس

الكورس يطلب منك أساليب محددة:
مثل:

* استخدام lambda
* استخدام list comprehension
* استخدام functions بدون loops أحيانًا
* استخدام map و filter

التست ما يقول لك *كيف* تحل، لكنه يقول لك *وش لازم تكون النتيجة*.

وانت تحل بطريقة الكورس.

---

# 🧠 مثال كامل من الكورس وشرحه

خلّينا ناخذ تمرين حقيقي من مجلد lambdas:

**test:**

```python
def test_multiply_by():
    multiply_by_3 = multiply_by(3)
    assert multiply_by_3(4) == 12
```

وش يخبرني هذا test؟

* فيه دالة اسمها `multiply_by`
* الدالة تستقبل رقم (3)
* وترجع دالة جديدة (closure / lambda)
* هذه الدالة الجديدة تضرب مدخلها × 3

الحل يكون:

```python
def multiply_by(n):
    return lambda x: x * n
```

التست يساعدك تفهم **شكل الدالة ووظيفتها** بدون ما تحتاج شرح خارجي.
