# 🎯 **ما هي الـ Capturing Groups؟**

هي طريقة في الـ regex تخليك **تمسكي أجزاء معيّنة من النص** بدل ما بس تتأكدي إنه يطابق pattern.

يعني بدل ما نسأل:

> "النص يطابق الشكل ولا لا؟"

نقدر نسأل:

> "شنو القطع اللي داخل النص؟"
> "وين الجزء الفلاني؟"
> "شنو كان الـ pattern اللي تكرّر؟"

---

# 🧠 **الفكرة ببساطة**

### ✨ لما تحطين pattern داخل أقواس `( )`

الـ regex engine:

1. **يلتقط** النص اللي طابق هذا الجزء
2. يخزّنه
3. تقدر تسترجعيه بواسطة backreference مثل `\1`, `\2`
4. أو بواسطة `match.group(1)` في بايثون

---

# 📌 مثال بسيط

```regex
(\d\d):(\d\d):(\d\d)
```

هنا عندك **ثلاث مجموعات**:

* المجموعة 1 → الساعات
* المجموعة 2 → الدقائق
* المجموعة 3 → الثواني

لو استخدمتيها ببايثون:

```python
match = re.fullmatch(r'(\d{2}):(\d{2}):(\d{2})', "12:34:56")
```

تقدرين تجيبين القيم:

```python
h = match.group(1)  # "12"
m = match.group(2)  # "34"
s = match.group(3)  # "56"
```

---

# 🎯 **ليش نحتاج capturing؟**

## ✔ 1) استخراج معلومات

مثل: الوقت، الإيميل، الـ ID…

## ✔ 2) التحقق من تكرار نفس pattern

هنا نستخدم **backreferences**:

```regex
(.+)\1  # sequence مكرر مرتين
```

الكورس استخدمها كثير في:

* twice_repeated
* thrice_repeated
* ababa structure

## ✔ 3) التعامل مع أجزاء اختيارية

مثل milliseconds:

```regex
(\d{2}):(\d{2}):(\d{2})(\.\d{3})?
```

---

# 📦 **Capturing Groups vs Non-Capturing Groups**

### ✔ Capturing `( )`

تلتقط وتحفظ

```
(\d{2})
```

### ✔ Non-capturing `(?: )`

نفس الشي لكن *لا تحتفظ بالمجموعة*

```
(?:\d{2})
```

الكورس يذكر non-capturing فقط لاحقًا.

---

# 🔥 **Backreferences — أجمل استخدام للـ capturing**

لو كتبتي:

```regex
(.)(.)\2\1
```

فهذا يطابق مثلًا:

```
abba
1221
XY Y X
```

لأن:

* المجموعة 1 = أول حرف
* المجموعة 2 = ثاني حرف
* بعدين نرجع نكتبهم بالعكس

---

# 📌 **أمثلة من التمارين اللي حلّيناها**

## ✔ twice_repeated

```regex
(.)\1
```

هنا:

* `(.)` = الحرف الأول
* `\1` = كرري نفس الحرف

---

## ✔ thrice_repeated

```regex
(.+)\1\1
```

هنا:

* `( .+ )` = sequence
* `\1\1` = كرّري sequence مرتين

---

## ✔ ababa

```regex
(.+)(.+)\1\2\1
```

هنا:

* group 1 = A
* group 2 = B
* ثم A B A B A

---

# 🧠 مثال مرسوم لشرح الفكرة

لو عندك النص:

```
abc123abc
```

والregex:

```
(abc)(123)\1
```

المجموعات:

```
(abc)   → group1
(123)   → group2
\1      → abc
```

المطابقة:

```
abc | 123 | abc
```
ايوه يا فهّامة، **هذا هو بالضبط لبّ الموضوع** — وفاهمة صح 100% 👌🔥
بس خلّيني أرتّب لك الفكرة بطريقة تخليها ترسخ في الدماغ:

# 🎯 الفكرة الذهبية للـ Capturing Groups

**الـ regex عادةً يشيّك النمط بس.**
لكن **capturing groups** تخليه:

### ✔ يقرأ أجزاء معيّنة من النص

### ✔ يخزّنها مؤقتًا

### ✔ ويرجع يستخدمها لاحقًا

إمّا:

1. **داخل نفس الـ regex** باستخدام backreferences
   مثل `\1`, `\2`
2. **في بايثون** باستخدام

   ```python
   match.group(1)
   ```

# 🧩 بمعنى آخر:

> **أنتِ تعلمّي الـ regex يقول:
> “أمسك لي هذا الجزء… حفظه… وبعد شوي أبغى أسترجعه.”**

كأنك تقولين:

> "هات لي الجزء A، بعدين الجزء B، وبعدين كرر A وبعدين B وبعدين A."

وهذا اللي سوّيناه في تمرين **ABABA**.

---

# 🌟 مثال يخلي الفكرة تنطّ للعين

## النص:

```
abc123abc
```

## regex:

```
(abc)(123)\1
```

الشرح:

* `(abc)` ← أمسكي "abc" وخزّنيها كـ group 1
* `(123)` ← أمسكي "123" وخزّنيها كـ group 2
* `\1` ← جيبي لي أول وحدة (abc) مرة ثانية

فالنتيجة لازم تكون:

```
abc | 123 | abc
```

---

# 🔥 مثال آخر: تأكيد أن sequence مكرر 3 مرات

```
(.+)\1\1
```

* `( .+ )` ← sequence واحد
* `\1\1` ← لازم يظهر نفس sequence مرتين ثانية

فـ:

```
abcabcabc → صح
121212 → صح
ababab → صح
abcabca → غلط
```
