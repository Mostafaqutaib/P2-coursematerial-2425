سؤال ممتاز 👌
**Substituting في regex** هو بالضبط “الاستبدال” — يعني **نلقى نمط معيّن في النص ونغيّره بشيء آخر** بدل ما بس نتحقق منه أو نستخرجه.

خلّيني أشرحها لك ببساطة وبأسلوب الكورس 👇

---

## 🔁 ما هو Substituting؟

في الـ regex:

* **matching** → هل النمط موجود؟
* **capturing** → إيش الجزء اللي طابق؟
* **substituting** → بدّل الجزء اللي طابق بشيء آخر

وفي بايثون نستخدم:

```python
re.sub(pattern, replacement, string)
```

---

## 🧠 الصيغة العامة

```python
re.sub(regex, replacement, text)
```

* `regex` → النمط اللي نبي نبدّله
* `replacement` → الشي الجديد
* `text` → النص الأصلي

وترجع **نص جديد** (ما تغيّر الأصلي).

---

## 📌 مثال بسيط جدًا

### نبي نشيل كل الأرقام:

```python
re.sub(r'\d', '', 'a1b2c3')
```

النتيجة:

```
'abc'
```

---

## ✨ مثال من الكورس (تنظيف نص)

### نخفي أرقام الهاتف:

```python
re.sub(r'\d', '*', 'Call me at 0478123456')
```

النتيجة:

```
'Call me at **********'
```

---

## 🎯 Substituting مع Capturing Groups (القوة الحقيقية)

هنا الموضوع يصير ممتع 😎

### مثال: عكس الاسم واللقب

```python
re.sub(r'(\w+)\s(\w+)', r'\2 \1', 'John Smith')
```

الشرح:

* `( \w+ )` → الاسم الأول (group 1)
* `( \w+ )` → الاسم الثاني (group 2)
* `\2 \1` → نرجّعهم بالعكس

النتيجة:

```
Smith John
```

---

## 🔥 مثال مهم من التمارين

### نبي نغير تنسيق الوقت:

```python
re.sub(r'(\d{2}):(\d{2}):(\d{2})', r'\3-\2-\1', '12:34:56')
```

النتيجة:

```
56-34-12
```

---

## 📦 Replacement كدالة (مستوى أعلى)

بدل ما يكون `replacement` نص، ممكن يكون **دالة**:

```python
def square(match):
    return str(int(match.group()) ** 2)

re.sub(r'\d+', square, '2 3 4')
```

النتيجة:

```
'4 9 16'
```

---

## 🧠 خلاصة سريعة (مهم للاختبار)

| العملية     | الدالة                |
| ----------- | --------------------- |
| تحقق        | `search`, `fullmatch` |
| استخراج     | `findall`, `groups`   |
| **استبدال** | ✅ `sub`               |

---

## 🧩 مقارنة سريعة

```python
text = "abc123def"
```

| الهدف       | الكود                         | النتيجة       |
| ----------- | ----------------------------- | ------------- |
| مطابقة      | `re.search(r'\d+', text)`     | Match         |
| استخراج     | `re.findall(r'\d+', text)`    | `['123']`     |
| **استبدال** | `re.sub(r'\d+', 'XXX', text)` | `'abcXXXdef'` |
